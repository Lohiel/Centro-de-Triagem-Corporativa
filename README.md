# CTC — EcoPonto Catador

Landing page estática do MVP EcoPonto Catador, com a identidade visual CTC.

## Executar localmente

Abra `index.html` no navegador. A página usa HTML, CSS e JavaScript, sem instalação de dependências ou etapa de build.
